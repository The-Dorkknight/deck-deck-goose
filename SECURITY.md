# Security

Please report security problems privately through this repository's **Security** tab (Report a vulnerability), not as a public issue. This is a work-in-progress hobby project with no warranty; I will look when I can.

What the tool does and does not do is described in [HOW_IT_WORKS.md](HOW_IT_WORKS.md). Granting `--filesystem=host` to a Flatpak app weakens that app's sandbox; that is a choice you make per app.
