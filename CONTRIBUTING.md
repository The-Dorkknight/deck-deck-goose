# Contributing

Bug reports with the output of **Check** and `python3 -m ddg disks` are the most useful thing right now (use the issue template). Pull requests are welcome; by submitting one you agree your contribution falls under the same [PolyForm Noncommercial 1.0.0](LICENSE.md) licence as the project, and Copyright stays with its author(s) with the Required Notice kept.

Run the tests with `python3 -m unittest discover -s tests`. Keep it standard-library only and light enough for an old laptop.
