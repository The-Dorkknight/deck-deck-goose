# Third-party software

The PolyForm Noncommercial licence in [LICENSE.md](LICENSE.md) covers only the code written for this project. Other software keeps its own licence and belongs to its authors.

This project uses no third-party Python packages (standard library only). It calls these programs if they are on your system: `lsblk` (util-linux), `flatpak`, `systemctl` (systemd), `udisksctl` (udisks2), `steam` (only to ask it to exit) and `btrfs` (btrfs-progs). It reads files written by the Steam client and shows artwork Steam has already downloaded to your computer; that artwork belongs to the games' publishers and is never copied into this project. It is not affiliated with or endorsed by Valve, Steam, Proton, Bazzite, Universal Blue, Fedora, KDE, Dolphin, Linux Mint, Nemo, Flatpak, Flathub, Double Commander, Krusader or Microsoft. "This PC" is simply a descriptive name for the folder. Links to the documentation we read are in [docs/RESEARCH.md](docs/RESEARCH.md); we link to it rather than quote it.

**Artwork and fonts (0.5.0).** The Deck Deck Goose picture was supplied by the project owner and is used with permission for this project. The wordmarks in generated tile art are drawn with *Inter* (SIL Open Font License 1.1, Rasmus Andersson) when it is installed on the machine that runs `tools/make_art.py`; the finished images are committed, so users do not need the font. `tools/make_art.py` and `tools/make_pdf.py` (build-time only, not needed to run the app) use Pillow, Markdown and Playwright. The Airlock feature calls `kwin_wayland`, `plasmashell`, `dbus-run-session`, `steamos-session-select`, `kdialog`/`zenity`, `notify-send` and `pkexec` if present. "Airlock" is a descriptive feature name. **Zombie-Deck (0.6.0).** `components/zombie-deck/` is a bundled copy of Zombie-Deck, also by Matthew Armstrong, under the same PolyForm Noncommercial licence; it has its own README, tests and notes. The Windows and macOS library engine comes from the sibling GameShelf project (same author, same licence). Windows compression uses `compact.exe`; macOS volume facts come from `mount`. Not affiliated with Valve, gamescope, ASUS (ROG Ally), Crateless or Handheld Ops.
